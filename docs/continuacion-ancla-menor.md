# Ancla menor en las continuaciones

Las rutas suaves reutilizan la clasificación de tónicas menores del motor.
Para comprobarlo en Crear, introduce `Cm9` o `Cm9 G7`, selecciona Calma y
genera las rutas. La primera conserva Do menor y llega a `Cmadd9`.
La regresión automatizada transpone el caso a las doce raíces para los
acordes menor sexta, menor novena y menor con séptima mayor.
